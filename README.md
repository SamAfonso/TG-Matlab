# TG - Samuel Afonso
This repository contains some results for the development of the TG (Trabalho de Graduação) for Instituto Tecnológico de Aeronáutica.

### resumo_1_caso.mlx
Contains a full processing and visualization of metrics and figures for 1 specific case.

### Processa_TIE_Samuel.m
Contains a function for processing the general treatment and filtering of the raw impedance signal.

### Automacao_TG_Samuel_v2.m
Contains a script to run the entire processing scheme for all cases, according to pre-determined cut frequencies, and output all necessary files.

### sweep_correlacao.m
Contains a script to process some cases for different cut frequencies, and output some metrics that help determine the best cut frequency.
